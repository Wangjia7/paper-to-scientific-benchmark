## 可复现性自检

- [ ] 论文证据与新合成假设分清
- [ ] 统一科学问题与平台要求的判断数量明确（与实验数不混淆）
- [ ] 每个判断有竞争解释、可识别对照和独立失分；无强行拼题/无关重建
- [ ] 同一目录下各物理标签仍可区分；如共享一张表，按列单独验收
- [ ] 输入/真值/生成器哈希与公私隔离正确
- [ ] 非 GPU Linux、预算内运行，记录实际参考耗时和完整 Agent 预算
- [ ] 强基线/机制消融显示具体科学假设的可解释失败
- [ ] 乱序、缺失、重复、NaN/Inf、错误单位、评分边界及独立扣分测试通过

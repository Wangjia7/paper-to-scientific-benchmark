# 00 — 强制论文适题性审核与直接拒绝规则

## 核心定位

审核的是**该论文是否能在用户的平台约束内衍生出真正有价值的科研 Agent 任务**，不是评价论文发表价值、引用数或作者工作质量。高水平论文同样可能不适合变成这个 benchmark。对“不值得改成题目”的论文必须直接给出 `REJECT`，不进行工程实现。

## 快速证据审读（不展开生成数据）

核实论文四处证据：摘要/主结论、至少一组关键图或证明、Methods 中的假设与未决问题、数据/代码可用性。没有读到的内容不推断。记录来源（页、节、图、式），区分 PAPER_DERIVED / EXTRAPOLATION / BENCHMARK_ASSUMPTION。

## 五条必要条件：必须全部满足才能 GO

1. **研究对象明确且问题真实**：可以用该论文明确支持的物理/科学机制构造可证伪命题，而不是人为发明与文章无关的故事。
2. **科研判断不可被题面给定**：Agent 必须对模型选择、可识别性、证据排除、方法取舍或系统误差解释作出判断。简单重复计算、套公式、按固定脚本运行不算。
3. **独立性达到平台门槛**：这里默认 ≥3 个不同的科学结论，每个有特有证据或对照、可独立得到的答案、独立失分。切分同一目标的不同样本、红移或阶段不算。平台若改门槛，以明确要求为准。
4. **真值可识别、评分可客观唯一**：存在真实公开数据的可复算真值、可信模拟器/植入实验或严格推导的真值，并可在输入证据下区分合理解释；评分阈值能在数据生成前定义。
5. **资源和数据可行**：使用合法可取的数据或有科学意义的合成代理，能够在规定硬件、总时长和工具范围内运行。

### 一票否决情形

- 只有一个既定算法的执行答案，即使公式复杂、跑很久，也判 `REJECT`。
- 整篇论文只有一个可用于评分的科学目标，其余“checkpoint”全部只是同一推断的输入/噪声分组：当 ≥3 为硬要求且无法找到真实独立的问题时判 `REJECT`。
- 不额外引入论文外的新机制便无法构造三问，且引入后失去论文相关性：判 `REJECT`，不捏造独立性。
- 关键真值在可用信息下原理上不可识别、无法唯一验收：判 `REJECT`。
- 所有合理公开/合成路径都无法满足平台 CPU/内存/时间：判 `REJECT`。
- 重要论文、强理论结果但不适合出题：仍可 `REJECT`，注意区分“研究价值”与“转题价值”。

### 区分确定拒绝与证据不足

`INSUFFICIENT_EVIDENCE` 仅用于可修复的输入缺口：论文附件缺页、补充方法缺失、资料无法访问、用户没有给出决定性的硬件/评分规则。此时暂停设计，并仅询问最小信息。缺少数据不必直接拒绝：先判断是否存在科学合理的公开/合成替代，不能因“还没下载”就拒绝。

## 禁止的规避策略

不能通过以下方式将 `REJECT` 改成 `GO`：

- 把同一盲预测拆成 A/B/C 三组或增加被预测目标数量；
- 删除任务中的公式，把同一确定算法伪装成自主判断；
- 任意注入噪声、缺失、特殊文件格式等工程障碍；
- 编造论文没有依据的系统误差机制或隐藏物理标签；
- 在没有可识别证据时单纯增加隐藏真值；
- 设置主观专家评价或模糊通过阈值。

## 判定模板（先写结论）

```text
论文：[标题/DOI/arXiv]
适题性结论：GO / REJECT / INSUFFICIENT_EVIDENCE
论文依据：[页/节/图/公式]
是否存在真正需要证据取舍的科学判断：是/否；依据...
是否存在≥3个互相独立、可证伪且可单独评分的结论：是/否；依据...
真值与评分是否可行：是/否；依据...
资源数据是否可行：是/否；依据...

若 REJECT：
结论：不建议将本论文改写为该平台科研 Agent 题目。
1. [具体科学原因]
2. [具体结构/独立性/真值/资源原因]
为什么不应硬凑：[...]。
已停止：不生成任务字段、合成数据、参考输出、评分程序。

若 INSUFFICIENT_EVIDENCE：
结论：当前证据不足，暂停改题。
关键缺失：[...]。
下一步仅需要：[...]。
```

## 与四版 FP lensing 案例对应的审核逻辑

V1：模型和所有变换都给定，执行题应回绝其**这一题型**；不能仅把论文整体拒绝（仍可能有另外的独立研究命题）。
V2：有真值但缺公开评分定义，属于可以修复的任务问题，不是论文本身不适合。
V3：40 个测试视场等价于同一预测目标，不满足三独立结论；若论文没有额外可辩护的科学问题则 `REJECT`，不能通过更换组名解决。
V4：具有 A/B/C 不同物理机制、独立证据和真值，因而有条件 `GO`。每项是否真正可识别仍需数据测试。

# 00 — 论文适题性价值筛选与直接拒绝

## 评估对象

检查的是**当前论文能否在目标平台约束内转化为真正需要科研判断、且可独立验收的 Agent 题目**，不是评价论文的学术质量、影响因子或作者能力。高质量论文可以不适合本平台。

## 证据阅读

至少核查：摘要与核心结论；一处关键图/证明；Methods 的假设与未解决之处；Data/Code availability。注明精确出处，区分论文已证、推论延伸和 benchmark 新增合成假设。没有看到的内容不应虚构。

## 五条 GO 必要条件

1. **统一且真实的科研目标**：研究对象/机制与论文有可追溯联系；科学结果值得辨别，不是编造机制凑考点。
2. **自主科学推断**：需要针对竞争解释、理论适用性、物理污染、偏差归因或策略取舍作出基于证据的判断，而非执行已给定算法或简单优化固定目标函数。
3. **判断的可证伪与评分独立性**：满足**目标平台实际要求的科学判断数量**（本对话相关评审要求三个，但不意味着三个独立实验）。每项结论可独立发现错误，彼此有内在科学联系。可共享单个模拟、校准样本、真值表或输出文件。
4. **证据足够识别真值、规则唯一**：每项科学结论都有可识别证据和独立可复算的真值/检验标准；公开评分公式/容差后，同一提交获得唯一结果。
5. **平台可运行**：合法数据或经过科学审查的合成代理，以及目标 CPU、内存、时长、工具约束下的可行求解路径。

## 一票否决情况

- 候选只剩已知公式复算、照指定步骤执行；增加工程难度也不会产生不同科学结论。
- 三个所谓“判断”只是同一预测目标的三个分组、阶段或数值转换，无法在当前平台要求下产生足够可证伪的不同科学命题。
- 为满足数量强行拼接三组无关实验，或增加论文没有支持的“独立物理机制”“组合式重建”。
- 所有候选科学目标的真值均不可由提供的证据识别，或任何客观评分会依赖主观意见。
- 无可合法提供且在硬件/时长预算内可用的合理数据/方法；真实模拟不可行时也没有科学成立的低成本代理。

`REJECT` 针对**当前转题任务**；不应宣称论文科学价值低。一个合理题型失败时，应先考察论文是否支持其他自然题型；若仍不可能，再拒绝整篇论文在此平台改题。

## 证据缺失不等于无价值

仅关键补充材料、数据许可证、计算限额等信息缺失且可以补齐时，标 `INSUFFICIENT_EVIDENCE`，暂停并索取最小缺口；不要把资源暂时不可得武断写成论文无科研价值。

## 明令禁止的包装

- 将同一预测拆成多个红移/噪声/种子 checkpoint 冒充科学判断；
- 隐藏公式、随机加噪、特殊数据格式来制造所谓创新；
- 未证明可识别性就注入独立真值；
- 将“独立性”简化为三个实验文件、三个不同物理标量或三份 CSV；
- 为通过评审而生成与论文本意无关的离散图对象或额外统计目标；
- 评分只写“尽可能准确”，或使用不可复算的文字观感打分。

## Gate −1 判定卡（必须先出结果）

```text
论文：[标题/DOI/arXiv 与页/式/图]
当前平台：要求的科研判断数[明确来源]；CPU/内存/运行时长[明确来源]
统一科研目标：[一句话]
候选科学判断：[每项命题 + 可识别证据 + 可独立扣分依据；可共享实验]
结论：GO / REJECT / INSUFFICIENT_EVIDENCE
理由：[科学判断是否不可替代，真值/资源是否可行]
若 REJECT：明确本轮停止数据、参考解和评分器开发。
若 INSUFFICIENT_EVIDENCE：明确当前缺失的最小决定性证据。
```

## 案例教训

- FP lensing V1：公式执行链应拒绝当前**题型**，不能因此否定论文全部可能性。
- FP lensing V2：未公开评分统计量属可修复的合同缺陷，不须重做论文价值审查。
- FP lensing V3：四组观测仍只有一条 κ 预测链，无法靠分组冒充多科学判断。
- FP lensing V4：据用户提供的评审反馈通过；采用三个实验是一种可行实现，**不是后续所有论文都必须仿照的形式**。
- Elbers LPT 旧版：三个彼此独立的合成测试（核误差回归、九选一优化、质量反演）仍被评审认定为科研解释不足；反例证明“独立实验+独立输出+独立分数”并不足以构成科研判断。

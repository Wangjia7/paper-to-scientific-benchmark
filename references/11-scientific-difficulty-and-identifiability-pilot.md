# 11 — 科研难度与因果可辨识性 Pilot（新增强制 Gate 1b / 4b）

## 目的

防止一个包含三个独立文件/真值/计分的题目，仍仅考核固定响应模型下的常规参数恢复。科学难度是**候选科学解释、证据选择、模型适用性、反事实控制及样本外信息增益**所造成的必需判断，不是机器运行复杂度、算法名称、行数或噪声大小。

## 输入与冻结时序

准备一份 Pilot 规格，先于生成正式隐藏种子冻结以下内容：研究问题、科学必要条件、可观测量、干预定义、建模自由度、数据生成族的物理来源、训练/开发/盲测隔离单位、常规基线、强参考解、时间/内存预算、判定原则。

应有**训练前**划分的几组独立开发条件；同一底层噪声实现、模拟相位、同一 halo 或来自同一视场的重复观测，不应被随机拆成完全独立的训练和验证样本。可使用 matched-phase 对照抵消噪声，但不能把相位匹配当成独立重复宇宙。

## 先验证“科学答案从可见数据中可辨识”

对每个被评分的隐藏目标，提供：

- `observable_evidence`：Agent 可见、能区分竞争解释的真实数据字段。
- `competing_mechanisms`：至少两个事前合理的物理/观测解释，不能只是同一模型不同参数。
- `controlled_counterfactual`：若需要因果归因，定义可执行的干预及与观测相符的 paired controls；说明目标是否交互或非线性、是否依赖干预顺序。
- `identifiability_probe`：构造观测统计近似相同而内部机制不同的反例，检查新增控制信息能否实际使其可区分。若仍不可辨识，不得强制评分单一机制标签，改为概率、集合、区间或明示不可判别的输出。
- `claim_scope`：参数恢复、预测关联、统计反事实、真实因果结论属于不同级别。静态关联或 PD 点匹配不能代替真实轨道/历史追踪。

## 七类实际参考/简单基线

挑选**与任务直接相关**的最少集合，不要求每题机械运行七项；但至少一条强、两条科学上可解释的常规/错误基线，并特别加入上轮审核使用的直接估计路线。

1. 题面给出的模板/已知函数最大似然或最小二乘（防 BAO V2）。
2. 以公开标定标签做常规回归、逐样本加权/校准（防将监督插值包装为科学发现）。
3. 不建模某一种必要系统误差的消融；如忽略 PSF 测量噪声。
4. 不利用额外物理信号的保守路线；如 GG-only（检验声称的 GI 增量）。
5. 无条件加入额外信号、不考虑相关协方差或模型失配的激进路线。
6. 仅使用固定形式/低阶近似、忽略族群/区域迁移的路线；如 FP 仪器仿射-only。
7. 简单标签泄漏、case ID 或可见元信息回归、行顺序/文件头/随机种子模式（防短路）。
8. **主动采样的无观测几何控制**：逐次最远点/maximin（至少两个独立实现）、k-center/空间覆盖、距离去重、一次排序、随机分层，以及对同一选点算法遮蔽光谱/观测/协方差/核的消融（防 Günther v9/B05）。只要它们合法通过必要科学门，就不能因算法名排除，须重审科学预算取舍。

“简单路线通过”不是需要扩大噪声或提高阈值的信号。若它达到所有科学必需门槛，停止并重新审查研究能力主张（甚至 REJECT）。若该方法在某些目标上确实有科学原理支持，则不应为了使其失败而添加与目标无关的机制。

## 难度证明的最低结构

对每条路线记录：公开输入摘要/哈希、实现命令与版本、是否只读 public、数据隔离单位、成功/失败的**每一个科学必要门**、总分、误差、独立开发种子结果、资源测试、日志路径。

至少应能展示：

- **强参考路线**仅用 public 可以达到必要门；若不能，这是不可解题而非高难题。
- **常规基线**在事先确定的、具有物理意义的至少一个必要门上失败；若各常规路线分别擅长不同部分，检查它们的简单组合能否全部通过。
- **失败必须可归因**于科学证据或机制混淆，而不是格式规则、隐藏答案的猜测或不合理的阈值。
- **跨开发种子稳定**：应展示可重复性与波动，不能用单一随机种子调整直到强模型刚好通过、弱模型刚好失败。
- **最终盲测种子在合同冻结后生成**。不能根据最终真值、隐藏标签或提交表现反向选择门槛/分布。

允许某简单基线总分很高，但因明确公开、确实必要的科学门槛失败；如 GG-only 可保守拟合，却不能证明 GI 增量信息。该门槛不能是基线跑完以后临时增加的。

## 一个必要判断可以来自同一科学实验

BAO V3 通过同一物理密度场、GG/GI、两种污染及其控制观测，形成真实性、反事实污染响应、增量测距三个可独立失败的判断，不需要互不相关的三套模拟。FP V4 设计确实用了相互独立的 A/B/C 数据实验，但这是该任务的具体选择，不是所有任务的强制结构。

## Gate 1c / B05 的独立物理试验

主动采样问题必须区分**仅候选布局变了**与**物理目标真的变了**：对前者即使 24 个布局全通过，也不能证明科学信息必要；对后者需固定新观测真值、响应谱、观测误差、后验支持区/尺度、GP 相关长度及随机种子，给相同预算的参考和简化方法公平比较。设计空间覆盖与观测后验出现真实冲突的实例，在冻结评分合同后验证，不得根据正式实例的最远点得分回调阈值。详细协议见 `references/13-observation-conditioned-budget-b05.md`。

`conditional_budget_pilot.py` 可以审计每个独立物理条件是否具有旧一次排序、几何覆盖、距离去重、条件化、参考和科学信息遮蔽对照，并检查分项、逐观测 JS、统一 grader、预先冻结及明显的合法旁路。它**不直接运行这些模型**，更不能用示例 JSON 充当科学证据。

## 输出状态

`PILOT_PASS`（证据充分、强路线通过、必要普通路线经科学失败、未泄漏、资源可行） / `PILOT_FAIL`（固定模型/普通路线覆盖全部必要条件，或真值不可辨识） / `PILOT_UNVERIFIED`（缺实际对照结果或独立新种子）。此处 Pilot 判定是**本地方法审查结果**，不等于平台审核。

可使用 `scripts/difficulty_pilot.py` 对结果文件的**完整性与逻辑条件**作守门；不能把该脚本视作研究深度的自动证明。

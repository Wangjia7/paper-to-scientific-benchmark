# 13 — B05：科学信息被几何覆盖旁路时，如何重新设计主动采样任务

> 2026-11-05 新增。来源为用户提供的 Günther 第 9 版 / v2.3 数据质检意见，所列分数均来自**用户转述的审核复验**，并非本次重新运行过的生成器。当前容器只具备 Günther v2.2 文件，**未获得**审核所用 v2.3 版本的 `generate.py`、`development/try_batch.py`、实际数据和审计日志；本文件不是 v10 已验证结论。

最远点路线的三个观测 JS = `[0.006496, 0.005615, 0.003314]`，均小于 `0.020`；B 六项门槛也通过。两种路线在未修改的旧 grader 上重新评分仍维持成败对照，说明修复不是简单加门槛；但**科学主动采样判断依旧可以完全跳过**。

**诊断**：不是评分器语法漏洞、不是算力不够，也不是简单方法“作弊”。这是**experiment–objective mismatch / scientific decision bypass**：任务声称需要根据观测后验和尺度预算决定点位，而任务分布和评价目标允许不使用观测的全域几何覆盖达到所有必要条件。即使有 24 种共享同一谱模型/先导/观测的候选坐标布局，也不能替代独立的物理/后验条件验证。

## 新增强制 Gate 1c：科学信息必要性反事实

先写明 Agent **必须使用哪一项科学信息**（如观测残差、各观测协方差、后验模式、核协方差或尺度敏感度）才能决定在哪里增加计算。然后构造“删去这项信息”的信息剥离基线，在**完全相同的候选集合、预算、评阅数据和原始评分契约**下测试。

1. 不知道物理目标时也可执行的强基线：随机分层、多次重启的最远点/maximin、空间填充/k-center、距离去重、固定格点、一次排序。**必须包括能够从上轮审核报告独立复现的原始算法**。
2. 保留物理目标但忽略更新的基线：仅按一次全局似然权重排列、不根据已选点更新剩余信息价值。
3. 科学信息消融：固定坐标与预算，遮蔽或置乱（按科学许可）观测数据、协方差、导数/响应或后验权重；比较结果和真正参考方法。
4. 参考路线：仅用 public 信息、能使用三个观测间的差异和已选点条件化变化，未见情况下仍满足所有必要门槛。
5. 记录：完整 A/B/C 分项、每个观测 JS、每项 B 的六个门槛、总分、全部质量门、运行命令和输入哈希；所有策略均通过**同一未修改 grader**评判。

只要一种不使用关键科学信息的**合法**方法通过所有必要条件，便应判定当前发行实例 `PILOT_FAIL / SCIENCE_DECISION_BYPASS`，不能按算法名称拒绝它，不能事后把 `S_min` 提高到其得分以上。

## 修复 C：让“在哪里投模拟预算”存在物理上可说明的冲突

保留 A、B、原有输出字段、候选约束、16 点预算、统一 GP 再训练和三个观测后验 JS 判据。**重点重新生成 `generate.py` 中的观测定义、响应与候选分布。**

建议的可检验设计，不是假装已经验证成功：

- **不同观测的科学目标不同**：三个观测应对应模型谱中**可物理解释的不同响应**（如低波数振幅、振荡/相位、非线性尺度阻尼）。它们产生不同的 `p_j(θ|d_j)` 支持区、方向/长宽比或多峰结构，而不是同一个后验中心和尺度的三份噪声副本。
- **同一 16 点预算存在竞争**：对同一组候选点，区域 A 中的模拟明显减少观测 1 的有效预测/对数似然不确定性，但对 2、3 收益有限；区域 B/C 反之。对全域做 k-center 在核心后验区域浪费相当预算，无法同时满足各观测已公开的 JS 性能目标。
- **候选点必须承载观测可解释的用途**：不允许仅按隐藏 `case_id` 对候选赋难度标签。公共先导光谱、响应与协方差应让 Agent 有证据定位哪些区域/参数方向信息价值更高，不应泄漏最终真值。对每个观测有合理的可辨识性与先导覆盖。
- **条件化不是算法独占要求**：允许贪心、批量组合、混合/分层方法；在核的相关性下边际收益可能随已选点而递减，因此要求科学上考虑 redundancy，但**不要求 API 或算法名出现 GP/conditional**。任何达到相同科学结论的简洁合法路线都应通过。
- **多种物理/后验设定验证**：除了 24 种不同候选布局，再独立改变观测真值、误差条/相关性、响应尺度、posterior centers/geometry、GP 有效相关长度，至少保证实际开发试验中存在多个不同的物理条件。训练/开发/最终盲测先冻结分组和随机种子，不对已看到的最终实例反复挑 seed。

可用的**候选设计代理量**（不是评分规定或唯一算法）：对于已观测/已选集合 `S`，条件方差更新的近似为

`Δv_S(θ | x) = cov_S(θ,x)^2 / [v_S(x) + σ_sim²]`

结合三组数据的当前后验、观测方向敏感度、光谱残差以及 `C_j^{-1}`，得到关于“增采某点能降低多大后验损失”的近似效用。在 `S` 改变后重新计算；必须用**隐藏的真实后验 JS**检验该代理是否真的有用。单纯把核方差乘上一个固定的全局似然权重，也可能仍无法区别最远点覆盖。

### 不能用来制造难度的手段

- 把数值精度从 `0.020` 调到某个刚好排除最远点的位置，或在看到最远点 `84.934793` 后调总分门槛。
- 只给某个后验区域赋一个强制得分标签，却没有先导科学证据和实际的观测敏感性依据。
- 删除合法算法、要求特定函数/模型代码，或按“最远点”方法名扣分。
- 对开发种子和候选布局逐个调参，最后只汇报参考路线通过的布局；对公共数据泄漏隐藏生成条件。

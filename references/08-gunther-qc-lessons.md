# 08 — Günther GP/PCA：连续两轮质检返修的可迁移教训

> 案例：Günther (2024), *Uncertainty-aware and Data-efficient Cosmological Emulation using Gaussian Processes and PCA*；本地 benchmark 是两参数、64 光谱 bin 的**解析代理**，不等于真实 Planck/CLASS/CAMB 测试。
>
> **证据来源**：用户提供的两轮平台质检原文；原 benchmark 的 `gunther_gp_pca_v2_1/QC_RESUBMISSION_REPORT.md`、`gunther_gp_pca_v2_2/QC_V4_B03_B04_REPORT.md`、对应 `private/grader.py` 和运行日志。用户给出的评审结论仅对这一题成立，不应上升为全部平台或物理领域的统一容差。

## 根因表

| ID | 质检指出的具体失败 | 违反的质量不变量 | 针对性修复 | 防复发测试 |
|---|---|---|---|---|
| B01 | B 的总分允许 LOW/MID/HIGH 之一的联合分布完全失效；全部 PCA 份额错误仍可能过线 | **科学必需结论不允许互相补分** | 对每个关键区域 × 每个必需目标分别加 hard gate；连续分数不变 | 单区域分布坏、单份额坏、全部份额坏，哪怕总分超线仍不通过 |
| B02 | 只有 `public/` ZIP，无法核验生成模型、隐藏真值、参考解和实际 grader | **评审可独立复算** | 提供保密 `private/` 包、公开数据专用参考解、固定随机种子生成器、哈希与执行日志 | 独立双目录再生与求解，只有 public 的环境求解，私有进程评分 |
| B03 | 极大但有限的均值使 KL 二次型溢出为 NaN，`max(0., NaN)` 变成 0 | **数值失败不得伪装为零损失** | 白化、缩放、对数域范数；所有中间量有限性检查；真 KL 超出浮点范围给科学门槛失败/明确数值故障 | `1e160`、`1e200`、正负交错、巨大协方差、NaN/Inf、KL 临界值 |

## 第一轮质检：B01 + B02

### B01：总分正确，不等于每个必须结论都正确

原 B 连续评分如下（每区联合误差分布最高 20/3 分，PCA 来源份额最高 10/3 分）：

\[
S_B=\sum_{j\in\{L,M,H\}}\left[\frac{20}{3}e^{-K_j/0.8}+\frac{10}{3}e^{-d_j/0.08}\right],\qquad d_j=|\hat f_j-f_j^{\rm truth}|.
\]

原来只设 `S_B>=18`。因此两个区域完全正确就得 20 分，第三个区域的全部联合统计可以被无条件放弃；三个区域的分布全部正确就获得 20 分，即使所有来源份额错误仍可能过线。这是**准入逻辑错误**，不是得分连续函数错误。

**已修复的本案例**：不删除连续分数，添加六个必要条件：

\[
\forall j\in\{LOW,MID,HIGH\}: \quad K_j\le 0.8,\quad
|\hat f_j-f_j^{\rm truth}|\le0.75 f_j^{\rm cal}.
\]

`f_cal` 由公开的每区 90 对残差计算，具体定义（PCA 协方差迹的相对份额）及 `ddof=1` 在 public README 披露。阈值取自重复抽样诊断而非随意调紧；240 次/区独立校准与评估抽样中，参考路线同时满足全部六条门槛的比例约为 98.33%。**只能将这个比例解释为指定合成抽样设计下的经验结果。**

原版暴露反例：LOW 均值 +100 且协方差设成 `10000I`，B 仍约 23.06/30，总分约 83.73/100；把所有来源份额置零，总分仍约 89.21/100。新版本对二者均作**全题不通过**判定，其它科学判断 A/C 的得分不被连坐。

### B02：只有题面、公开数据不能替代私有评阅证据

评审必须能够拿到一个**保密且完整**的复验包：

- `generate.py` / 等价模拟器：完整生成方法、参数范围、种子、抽样规则、数据版本；公开与隐藏残差需来自声明的同一总体（不能仅证明使用同一物理公式）。
- 只依赖 public 的 `reference_solver.py`：必须在不给任何隐藏真值/生成器的容器中真实运行；不能把 `private/` 复制到 Agent 侧。
- `grader.py`、隐藏真值、预期输出、环境及入口命令、反例审计、重复采样测试、哈希与实测时长/RSS。
- 公开题面、`README_AGENT.md`、`SCHEMA.json` 与私有 grader 的同一契约版本；**评阅包仅送评审，绝不能上传到 Agent 输入**。

缺失时只写“尚未提供可独立复验的文件”，**不能宣称已经完成**，也不把材料不可取得误写为证明作者根本未编写程序。

## 第二轮质检：B03 + B04

### B03：有限输入也可能造成非有限的中间量

错误模式：`NaN` 进入 Python 的 `max(0., float(KL))`，在当前实现中反而得到 0。直接验证 `isfinite(mean)`、`isfinite(cov)` **不够**：二次型、矩阵乘法、Cholesky 解、trace、logdet、loss、分数等每一步都需检查。

本例中，在 `uncertainty.npz` 只把 `mean(3,8)` 改为有限 float64 的 `1e160`，旧 grader 报 KL 为零且 `passed=true`；改成 `1e200`、正负交错等也暴露此类错误。修复原则：

1. 在作极大均值差减法前按共同尺度缩放；以 Cholesky 白化协方差、均值差；对于二次型使用稳定范数/对数域表示。
2. 对全部中间操作采取 fail-closed：非法数值应使该输出无效；数学上的极大 KL 若超过可表示范围，应作为 **超过质量门槛**，诊断用 `null`/明确标记，而非 `0`。
3. 对负 KL 只容忍经过证明的浮点舍入量级（该案例允许 `-1e-10` 以内），显著负值直接报错；**不能对任何 NaN 使用 max/clamp**。
4. 不应另加没有物理依据的 `abs(mean) < 常数` 隐藏硬阈值；应解决数值计算和失败处理。
5. 对 KL、loglikelihood、矩阵条件数、平方误差、归一化、指数等所有风险算子执行有限性及异常范围测试。

### B04：原始字符串不同，不代表科学候选不同

对候选 ID，必须明确规范文本（如 `P[0-9]{4}` ASCII）和**公开候选全集**，逐项检测规范格式、成员资格、规范映射后的唯一性，不允许通过 `str.isdigit()` 让 Unicode 字符被宽松解释。不允许同一候选拥有 `P0232` 与 `P０２３２` 两个名称进而绕过 16 个**独立点**限制。

CSV 严格读取必须先验证表头精确且无重复、行的**物理列数**等于表头列数、必需单元格非空、ID 集合/行数正确；不能依赖 `DictReader` 自动忽略意外列。合法 RFC CSV 引号、允许的行重排、NPZ 文件条目顺序、数学上等价的 dtype 字节序（如果合同允许）不应被误拒。

### 事实边界

本地整改报告记载旧版 65 项审计、新增 113 项回归断言通过；正确参考解保持约 `A=24.73749, B=29.19456, C=35.93167, S=89.86372`。这证明**已测试的反例**得到修正；不等于评分器在全部浮点、解析边界上获得形式化证明，也不等于平台下一轮人工质检必然通过。

## 推广到所有未来题目的发布前强制检查

### QC-1：科学必要条件矩阵（任务设计阶段完成）

用 `域/人群/条件 × 科学必要目标` 构建覆盖矩阵，标明每格的公开阈值、计算公式、独立参考与为何必须合格。**不是每个普通诊断量都强制 gate**；需要解释为什么某格科学上不可缺。若 `S` 及某子分数全过，但任一必需格严重错误，全题必须不通过，同时继续报告其他独立任务分数。见 `assets/qc-coverage-matrix.example.json` 与 `scripts/qc_matrix.py`。

### QC-2：自包含的评阅交付证据（工程阶段完成）

必须交付 `public.zip`、`private_scoring.zip`、生成/版本/抽样说明、仅 public 求解的参考程序、运行命令、机器可读审计日志。只有展示正例高分是不充分的。若平台当前只允许编辑题目设计，设计说明先更新；私有包待配置阶段同步替换，或单独提供评阅通道。

### QC-3：评分器安全红队（工程阶段强制实际运行）

至少覆盖：极大但有限的正负数、NaN/Inf、奇异/边界 PSD 协方差、严重负 KL/无效中间量、规范对象别名、重复真实对象、CSV extra/missing cells、重复表头、合法引号/行重排、矩阵字节序。每条需实际调用当前版本的 grader 产生结果，记录预期/实测与其他任务分数是否保持独立。

### QC-4：不得只修题面

每次修改必须同步：任务问题 → 任务价值/公开评分 → `README_AGENT.md` → `SCHEMA.json` → 私有 grader → 审计/重复抽样 → 打包与哈希。发现上一轮未覆盖的新漏洞必须新增回归测试，避免返工。

### QC-5：发布声明的级别

- `设计候选`：科学方向可能成立，但证据、阈值或私有包未完成。
- `可复现原型`：参考解与现有回归集跑通，但未覆盖必要红队。
- `本地质检就绪`：正例、等价例、必要科学失败例、数值及序列化攻击、公开/私有隔离和资源实测全部通过。
- `平台通过`：**只有获得平台实际结果后才能声明**；此前任何自检不等于平台通过。

# 02 — 三项科学判断的独立性验收

**最终通过案例的最重要教训：必须在产生数据前证明科学判断独立。** 三项研究应属于同一主题，但不能只是在一个结果上添加三道工序。

## 三问矩阵（每行须完整）

| 判断 | 独立科学命题 | 可见证据/校准 | 隐藏真值及单位 | 对照/失效模式 | 交付文件 | 独立评分门槛 |
|---|---|---|---|---|---|---|
| A | | | | | | |
| B | | | | | | |
| C | | | | | | |

最少检查：**不同结论**、**不同可识别证据**、**各自独立真值**、**各自独立数值评分**。同一母数据可以复用，但每项的独立标签/科学识别逻辑不能复用成同一输出量。

## 五个反事实问题

1. **完美 A 测试**：如果 Agent 已知道 A 的全部真值，是否仍然需要新的证据才能回答 B？若不需要，B 大概率只是 A 的派生量。
2. **故意失败测试**：A 预测正确而 B 错误时，评分器能否只扣 B 的分？若“不会/没单独真值”，不独立。
3. **证据分离测试**：去掉 B 特有的观测/对照，B 是否失去可识别性而 A 仍可做？若两者完全等价，要重新找 B。
4. **机制消融测试**：找一个对 A 合理、但对 B 因另一物理机制而失败的简化科学模型；运行结果是否显示 B 专属的惩罚？
5. **同一目标压缩测试**：能否把三份答案换成一份相同参数的预测表，且不丢失研究意义？若能，说明可能只是分组重复。

至少 #1、#2、#4 必须有确定“可以区别”的证据；所有问答最终还需领域专家审核，不能靠脚本自动证明。

## 科学难度 vs 工程复杂度

合格的不同假设：
- 物理污染 / 零点漂移两种解释，靠红移局域性和负对照识别；
- 仪器仿射偏差 / 非线性偏差在不同样本分布上的转移；
- 选源响应理论修正 / 经验标定 / 分层统计模型的泛化差异。

不合格的复杂性：
- 将样本从 40 扩大到 400；
- 用 4 个独立随机种子预测同一个量；
- 同一估计量分别以 CSV/JSON/PDF 输出；
- 固定全部物理变换，只让 Agent 写性能更好的计算代码；
- 把「FP 拟合→响应校准→汇聚度输出」三个必经步骤分成三个有分数的 checkpoint（除非其中一个步骤确实构成自身独立的科学命题、可识别真值与独立证据）。

## 建议的评分结构

总分 = 各项独立分数之和；同时设置子任务最低门槛。这样「A 满分、B 完全失败、C 满分」不能通过。要预先检查门槛是否可同时满足，以及最弱合法策略能否靠碰运气或恒预测获取高分。

> 形式化必要条件并非充分条件。三份 CSV、三组分数不能自动构成三个科学判断：证据和结论必须真正不同。

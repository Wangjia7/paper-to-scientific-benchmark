# 02 — 科学判断的独立性与统一性审查

**不要混淆三类独立性：** 实验彼此独立 ≠ 科学判断可独立证伪 ≠ 评分 checkpoint 可独立扣分。当前目标平台的评审关注后两者，**不要求每个判断使用独立模拟、独立观测目录、独立真值文件**。

## 先定统一科学问题，再决定多少实验

在设计数据前用一句话写出**完整研究目标**。在此基础上列出平台要求数量的科学判断（本对话中的特定评审要求三个；不是普遍规律）：

| 判断 | 在统一问题中的科学命题 | 竞争性解释/预期因果关系 | 支持或否定的证据/对照（可共享数据） | 可证伪结论与真值出处 | 专属失败模式及扣分规则 |
|---|---|---|---|---|---|
| A | | | | | |
| B | | | | | |
| C | | | | | |

**数据层**：可以只有一份目录、一次成组模拟、一张联合真值表和一个提交 CSV。相同观测数据之所以支持多个判断，是因为其不同扰动方向、对照、尺度或统计关系对不同科学解释提供不同的辨识能力。共享不等于不独立，但必须论证**可识别性**，不能只声明“同一目录含很多列”。

**结论层**：判断必须具有不同的可证伪命题。它们可能依赖相同的物理参数甚至共享后验，但不能全部只是输出同一隐变量的另一次回归。一个判断的真值已知不应在逻辑上自动决定其余所有判断。

**评分层**：同一 CSV 中不同列可以按不同真值/诊断量计分。同一真值表也能含多个标签；独立评分后果比独立文件名重要。对任一判断的错误，评分器应能仅扣这一判断相关的分数。

## 五项反事实检验

1. **问题不可替代**：A 完全正确后，B 是否仍然要判断新的科学命题（例如数值误差来源而非误差大小）？如果 B 只是 A 的必然代数推论，则不独立。
2. **专属失效**：能否构造科学上合理的策略，使 A 正确而 B 错误，且能在独立真值/对照上发现 B 的错误？
3. **证据区分**：在共享模拟中，哪一种干预/对照/变量变化可识别 B 而不能直接由 A 推出？如果删去这部分信息后 B 就变得不可识别，说明这部分证据具有独特作用；不需要另做一套模拟。
4. **信息流方向**：如果 A 是建模、B 是同一响应系数校准、C 是同一 κ 的计算，它们是不是一条必需的计算链？若是，不能仅靠三项分数声明三个判断。
5. **统一性与研究意义**：删去某一判断，整个研究论证失去何种科研结论？若一项只为凑数量、没有论文或领域机制支撑，即使有独立真值也应删除，必要时 REJECT。

**必要证据**：尤其要通过 1、2、5。脚本只能测试文件与数值行为，不能自动作出科学独立性的判定。

## 对照实例

**合理的单一研究项目（Elbers et al. 论文的候选结构，尚需实际数据验证）：** 在同一批共相位、不同 LPT 阶数/起始红移/粒子分辨率及中微子质量的模拟中，分别判断（A）误差来源是截断还是离散化，（B）尺度无关中微子近似在哪些构型/精度下成立，（C）相同初始条件与质量比是否真的抵消数值误差并影响中微子质量推断。这些问题关联紧密、可共享绝大部分数据；但**要分别设计可排除竞争解释的对照和可计算真值，才能认定其独立**。

**不合理：** 单纯把 `κ` 预测分成低红移/高红移/强噪声三组；把 `FP拟合→校准→κ预测` 三步各赋一个分数；用 40 个不同种子预测同一变量；为了强调组合重建而强行加入与目标无关的傅里叶超图。

**同样不合理的另一极端：** 固定函数误差数值预测＋按预给成本从九个备选中选最小＋从定好的模板反演质量参数，即使三者使用互不相干的合成数据，也可能缺少对科学解释的真正选择。独立实验数量不等于科研判断深度。

## 评分结构建议

在满足明确的平台 checkpoint 规则前提下，使用每个科学命题可独立得分的指标，并设置能阻止放弃关键结论的最低要求。一个判断允许多个数值 checkpoint；一个统一预测文件可以含多列。**评分独立**不要求实验、真值文件或代码模块隔离。

> 验收最核心的问题：Agent 是否必须用数据排除某个合理的科学解释？每个答案是否可以单独被证伪？全部结论是否共同服务于一个有意义的科学目标？

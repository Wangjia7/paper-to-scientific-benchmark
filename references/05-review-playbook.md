# 05 — 评审红队与定向修订手册

## 三次未通过的明确归因

| 版本 | 评审指出的缺陷 | 表面上看合理的设计 | 真正的问题 | 正确修复 |
|---|---|---|---|---|
| V1 | “Agent 只需执行既定模型…没有足够科研判断难度” | 参考 FP、复杂选源、有限差分、乘性偏差、多个 checkpoint | 论文 Methods 被变成配方；错误只会是执行错误 | 把隐藏物理机制留作验证对象；让 Agent 判断模型与偏差/泛化，依据校准证据选择路线 |
| V2 | “没有定义误差统计量、40 场汇总方式或明确合格判据” | 有独立盲真值，预测单一 κ | 真值唯一、评分**不**唯一；公开目标不可操作性验收 | 明确公开误差定义、分组权重、绝对容差、通过门槛、非法输出规则；私有评分器严格同构 |
| V3 | “40 个视场只是同类规则重复…没有三个不同证据和独立评分后果的科学判断” | 四类工况，各 10 视场，计分精细 | 仍是一条 FP→校准→κ 预测链，多个类别非多个物理结论 | 新建 B 本征关联幅度、C 仪器响应乘性偏差，给各自校准/盲测、独立真值、文件与子任务门槛 |
| V4 | 用户报告“最终通过” | 三项同一主题下不同目标，联合总分 | 对前述问题形成了结构性修复 | 将三道失败闸门写进 Skill，前移审核节点 |

**重要边界：** V4 已通过是用户在本对话提供的结果；本 Skill 没有登录平台复查其评审记录。参考方法的数值测试来自已生成的 V4 文档，不意味着所有 Agent 的完成率已实测。

## 在评审前先问：是否应该直接否决这篇论文？

每个题目必须先通过 `references/00-value-screening.md`。如果论文只有公式复算价值、没有足够独立的科学命题，或只能靠无关假设生成三问，应评为 `REJECT`，不要进入评审模拟。**针对 V1 的配方题可以否决这一题型，而不是武断地否决整篇论文的其他改题可能；针对 V3 若已无真正独立的科学目标则拒绝转换。**

## 评审模拟的十问

1. 给定全部公开参数和唯一模型后，是否只剩线性代数/查表/软件工程？
2. 在不犯编程错误的前提下，两名领域专家能否选择不同合理方案并得到不同科学推断？
3. 三个判断的答案是什么？若都是 `kappa_ref`，重做独立性设计。
4. A 已经做完时，B/C 有没有新的科学问题、证据和独立真值？
5. 是否有一个简单/错误策略只对某个独立判断失败？是否展示过消融？
6. 公开题面有没有唯一评分统计量、分组数量、权重和全部通过条件？
7. 隐藏的是否只有真值（及具体组映射），而不是偷偷追加的评分规则？
8. 数据与代码能否在新 Linux 无 GPU 容器按文件清单复现？
9. 任何公开数据是否泄漏私有真值、未授权的模拟器、答案索引或文件名映射？
10. 能否在 5h 内完成完整 Agent 生命周期，而不只是参考程序跑几秒？

任一 1–7 答案不能自洽时，不建议提交正式想法；8–10 不通过时，不建议提交任务配置。

## 有针对性的修订策略

**A. 只给一个拒绝结论、没逐条意见：** 将核心句子映射到「科学判断」「独立性」「评分唯一性」「数据/可解性」「运行约束」五类之一；优先修根因。不要基于“提高难度”笼统加噪声、增大量。

**B. 评分规则被指出不确定：** 只需要固定计分契约并公开，通常不用改变数据/科学目标。必须同时更新公共题面、公开 README、私有评分器，并运行断言测试。

**C. 科研判断不独立：** 必须新增独立科学证据、模拟真值、输出、评分后果；修改一个字段绝不够，必须同步更换公开 ZIP、私有评分包和文案。

**D. 提案声称三个判断但题目松散拼接：** 用一段统一科研问题串联（测量可靠性/模型可证伪性），证明每问在论文不同机制上起作用；再用互相独立的观测/对照验证。不可人为选三个完全不相关题目凑数量。

**E. 参考方法表现太好/数据可机器学习直接拟合：** 不因此立刻加大数据或隐藏更多信息；检视判断是否真的需要科学建模、是否存在短路特征、校准是否泄漏、是否有真正的分布迁移和负对照，以及目标的可识别性。

# 03 — 先写验收契约，再生成数据

## 对 Agent 公开的评分必要信息

每一个可证伪科学判断至少说明（同一组共享观测也适用）：

1. 科学参数的精确定义、符号、单位、参考尺度/参考红移、样本成员约定；
2. 输出文件名、精确表头、主键、数据行数和允许的数值格式；**多个判断可以写入同一 CSV 的不同列**，不要求三个文件；
3. **唯一**比较统计量（例如绝对误差、标准化残差、固定精度的某个统计检验）；
4. 误差比较边界（`<=` 或 `<`）、阈值、分组大小与权重；
5. 分组得分和总分的计算公式、整体通过阈值；
6. 各独立判断的最低得分及关键子组最低通过数；
7. 缺失、重复、非法 ID，缺字段、NaN/Inf、空值、无效 CSV 的明确处置；
8. 哪些信息隐藏：真值与具体 ID→物理组映射可以隐藏；**评分公式不可隐藏**。

推荐使用确定性的逐条阈值评分：

`e_i = abs(pred_i - truth_i)`；`p_i = 1 if e_i <= tolerance_of_group else 0`；

`S_g = weight_g * sum(p_i for i in group) / N_g`；

`S = sum(S_g)`；通过当且仅当输出合法、`S >= total_pass_score`、全部独立子任务得分 `>= min_score`，以及全部关键组的 `n_pass >= min_pass`。

**分组可代表不同的科学失效机制**（而非任意复制）；它们只是每项判断内部的稳健性测试，不能冒充独立科学判断。

**共享输入与真值**：三个判断可以复用同一批 `case_id`、同一份校准样本或私有真值表。验收时每一判断有明确、非自动推导的科学命题和独立比较字段；评分器可以按列独立失分。要避免将三份输出文件的数量误当成科学独立性证据。

## 新增：必要科学结果（hard gate）与加权分数不得互补

**在开始合成数据之前，列出所有科学目标与观测域的必要性矩阵。** 对于科学上要求在每个子域都可靠的结论，逐域规定不可补偿的验收条件：

`passed = files_valid and (S >= S_min) and all(judgment_min_scores) and all(necessary_science_gates)`。

Günther 示例：三块参数区域（LOW/MID/HIGH）× 两类必要输出（联合均值/协方差 KL、PCA 来源份额）＝**六个必要质量条件**。只检查 B≥18 无法排除某一子域失败或全部份额错误。门槛由独立重复抽样及公开可用的校准估计确定并**冻结、公开**；不能仅把 18 略微调高。具体反例详见 `references/08-gunther-qc-lessons.md`。

强制执行**补分攻击**：分别将每一必需格严重破坏，保持其它输出为正确参考；如 `score >= total_pass_score` 或子分数达线，`passed` 仍必须 false，且其它独立科学判断应报告与参考相同的数值分数。不存在不可补偿理由的普通诊断量仍可采用连续评分，不把所有字段都升格为硬门槛。

## 唯一判定不等于唯一科学方法

允许等价/不同推断算法得出接近的物理结果。真值、误差与通过判定唯一，方法不唯一。这是科学 benchmark 的目标，不应根据解法结构、语言表述、绘图风格、代码效率主观给分。

## 定标容差的方法

- 通过单位和物理尺度分析确认误差绝对量级合理；例如 `0.01` 汇聚度 ≠ `0.01 dex` 尺寸残差。
- 用统计噪声估计、有限差分截断误差、数据精度、参考方案跨种子验证提出阈值。
- 用「强基线」「弱基线」「常数/作弊基线」分布检查是否过松/过紧；**不要**为了让某个参考方案过线而反复查看隐藏样本并调整阈值直到凑分。
- 保留零值、负值、边界刚好等于容差、严重离群值；公开边界等号约定。
- 固定阈值后进行最终锁定，记录版本/哈希；隐藏真值不可在任务开放后改变。

## 防止数据/评分泄漏

- 数据生成器和注入真值应放在 `private/`，不放入 Agent 的 ZIP。随机种子本身如可复现隐藏标签映射，也必须私有；公开可提供本来就允许再生的观测母样本随机性。
- 检查公开 README、元数据、文件名、ZIP 条目是否含 `blind_truth.csv`、`grade.py`、`build_hidden.py`、预测真值表或可解码答案的编码。
- 公共数据的校准标签是合法信息；它们不得以索引/排序泄漏隐藏预测目标。
- 由访问受限的独立评分进程读取私有真值；输出只能依赖提交文件，不能根据模型源码或分析文字评分。
- 推荐记录生成器 git revision、依赖版本、输入与私有真值 SHA256、测试环境与实际执行日志。

## 输出非法的处理

推荐：一个**判断对应的输出字段/文件**非法则该判断得分置零，其余合法字段正常评分；整体通过为 false。共享 CSV 时可规定整表结构缺失则全部失效，但单列 NaN/Inf 应能只扣对应判断，并在题面公开该规则。不能因为文件共享就把三项科学分数变成不可分的评分链。若平台另有规定须同步调整题面和 grader。

## 数值计算与真实对象的安全合同

不得仅检查输入 `isfinite`，还必须对平方、矩阵求解、迹、logdet、KL、损失和得分等所有可能溢出的**中间结果**检查；有限极端值导致损失无法表示时必须 **fail closed**。CSV 逐行严格字段数及表头；候选 ID 必须来自公开规范集合，映射后再查重；合法 CSV 引号/行重排、允许的浮点字节序保持科学等价。参见 `references/09-grader-quality-assurance.md`。

## 验收器测试矩阵

| 测试 | 预期 |
|---|---|
| 真值原样提交 | 满分且通过 |
| 打乱行序 | 相同分数 |
| 恰好在阈值边界 | 判通过 |
| 阈值外 +epsilon | 判不通过 |
| NaN / Inf / 空值 | 对应文件无效 |
| 缺 ID / 重复 ID / 未知 ID | 对应文件无效 |
| 只把共享 CSV 的 B 列全部预测成明显错误 | A 与 C 不变，B 单独扣分 |
| 全预测 0 / 全预测均值 | 不应仅靠先验轻易过全部科学任务 |
| 单位错一百/一千倍 | 产生可解释的数值失败 |
| 训练目录加入 hidden truth | 防泄漏检查阻止发布 |
| 某一区域均值/协方差极错而总分仍达线 | 硬质量门失败，其他判断分数不变 |
| 仅来源份额错误或全部份额错误 | 不被联合分布高分补偿 |
| float64 有限极端值使 KL 中间量溢出 | 不得映射零损失、NaN 得分或通过 |
| Unicode 全角 ID 别名、真实候选重复 | 必须拒绝，按公开候选全集验证 |
| CSV 行额外/缺少一个字段 | 严格拒绝，不能被 DictReader 静默丢弃 |
| 合法 CSV 引号/重排、允许浮点大小端 | 结果不变 |
| 缺失私有评分包或参考解仅能在私有环境运行 | 禁止宣称端到端可复验 |

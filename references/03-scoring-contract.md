# 03 — 先写验收契约，再生成数据

## 对 Agent 公开的评分必要信息

每一个独立判断至少说明：

1. 科学参数的精确定义、符号、单位、参考尺度/参考红移、样本成员约定；
2. 输出文件名、精确表头、主键、数据行数和允许的数值格式；
3. **唯一**比较统计量（例如绝对误差、标准化残差、固定精度的某个统计检验）；
4. 误差比较边界（`<=` 或 `<`）、阈值、分组大小与权重；
5. 分组得分和总分的计算公式、整体通过阈值；
6. 各独立判断的最低得分及关键子组最低通过数；
7. 缺失、重复、非法 ID，缺字段、NaN/Inf、空值、无效 CSV 的明确处置；
8. 哪些信息隐藏：真值与具体 ID→物理组映射可以隐藏；**评分公式不可隐藏**。

推荐使用确定性的逐条阈值评分：

`e_i = abs(pred_i - truth_i)`；`p_i = 1 if e_i <= tolerance_of_group else 0`；

`S_g = weight_g * sum(p_i for i in group) / N_g`；

`S = sum(S_g)`；通过当且仅当输出合法、`S >= total_pass_score`、全部独立子任务得分 `>= min_score`，以及全部关键组的 `n_pass >= min_pass`。

**分组要代表不同的科学失效机制**（而非任意复制）；它们只是每项判断内部的稳健性测试，不能冒充独立科学判断。

## 唯一判定不等于唯一科学方法

允许等价/不同推断算法得出接近的物理结果。真值、误差与通过判定唯一，方法不唯一。这是科学 benchmark 的目标，不应根据解法结构、语言表述、绘图风格、代码效率主观给分。

## 定标容差的方法

- 通过单位和物理尺度分析确认误差绝对量级合理；例如 `0.01` 汇聚度 ≠ `0.01 dex` 尺寸残差。
- 用统计噪声估计、有限差分截断误差、数据精度、参考方案跨种子验证提出阈值。
- 用「强基线」「弱基线」「常数/作弊基线」分布检查是否过松/过紧；**不要**为了让某个参考方案过线而反复查看隐藏样本并调整阈值直到凑分。
- 保留零值、负值、边界刚好等于容差、严重离群值；公开边界等号约定。
- 固定阈值后进行最终锁定，记录版本/哈希；隐藏真值不可在任务开放后改变。

## 防止数据/评分泄漏

- 数据生成器和注入真值应放在 `private/`，不放入 Agent 的 ZIP。随机种子本身如可复现隐藏标签映射，也必须私有；公开可提供本来就允许再生的观测母样本随机性。
- 检查公开 README、元数据、文件名、ZIP 条目是否含 `blind_truth.csv`、`grade.py`、`build_hidden.py`、预测真值表或可解码答案的编码。
- 公共数据的校准标签是合法信息；它们不得以索引/排序泄漏隐藏预测目标。
- 由访问受限的独立评分进程读取私有真值；输出只能依赖提交文件，不能根据模型源码或分析文字评分。
- 推荐记录生成器 git revision、依赖版本、输入与私有真值 SHA256、测试环境与实际执行日志。

## 输出非法的处理

推荐：一个子任务文件非法则该子任务得分置零，其他合法文件正常评分；整体通过为 false。这样不会错误地把三项变成强耦合的全有或全无评分；但也明确禁止缺交付而侥幸合格。若平台另有规则，要前后一致地替换公开和私有实现。

## 验收器测试矩阵

| 测试 | 预期 |
|---|---|
| 真值原样提交 | 满分且通过 |
| 打乱行序 | 相同分数 |
| 恰好在阈值边界 | 判通过 |
| 阈值外 +epsilon | 判不通过 |
| NaN / Inf / 空值 | 对应文件无效 |
| 缺 ID / 重复 ID / 未知 ID | 对应文件无效 |
| 只把 B 全部预测成明显错误 | A 与 C 不变，B 单独扣分 |
| 全预测 0 / 全预测均值 | 不应仅靠先验轻易过全部科学任务 |
| 单位错一百/一千倍 | 产生可解释的数值失败 |
| 训练目录加入 hidden truth | 防泄漏检查阻止发布 |
